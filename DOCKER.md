# Docker

Актуальная инструкция: [README.md](README.md).

Используйте **корневой Dockerfile** и сервис `app` в `compose.yaml`.
Старая схема из отдельных backend/frontend контейнеров заменена одним
приложением с браузерной камерой. Старые контейнеры можно остановить отдельно;
исходная SQLite-база не изменена.
